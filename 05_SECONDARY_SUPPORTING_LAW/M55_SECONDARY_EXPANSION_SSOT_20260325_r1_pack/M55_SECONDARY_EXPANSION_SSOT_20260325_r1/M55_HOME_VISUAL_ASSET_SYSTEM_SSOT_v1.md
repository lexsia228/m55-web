## 0. Executive judgment

M55 の画像資産は「神秘演出」ではなく「観測の編集物」に寄せる。
Home の画像は aura を売るためではなく、
**データが見える / deeper layer がある / でも無料では全部は見えない**
を一瞬で理解させるために使う。

---

## 1. Asset system goal

### 1.1 What visual assets must do
- self-projection を起こす
- data visibility を強める
- report depth の存在を匂わせる
- trust を下げない
- occult cliché に落ちない

### 1.2 What visual assets must not do
- score/rank 感を出す
- fake scarcity を補強する
- cheap mystical app に見せる
- free lane を complete-feeling にしすぎる

---

## 2. Allowed asset families

### 2.1 Primary families
- editorial infographic background
- quiet atlas / map-like composition
- specimen / cutaway / layered plate
- symbolic object study
- muted geometric field
- paper-like editorial spread texture

### 2.2 Optional families
- calm portrait silhouette
- architectural void / corridor / threshold
- restrained constellation grid used only as background motif

### 2.3 Forbidden families
- crystal ball cliché
- purple-only mystical nebula wall
- tarot-card cliché on current home hero
- screaming “fortune app” iconography
- exaggerated cosmic lightning / glowing eyes / occult horror
- countdown-sale visual treatment

---

## 3. Home asset count rule

### 3.1 Hard limit
Home must remain light and readable.

Allowed count:
- hero illustration: `1`
- data-support illustration: `1`
- blurred spread teaser: `1`
- optional micro-support visual: `1`

Recommended total visible major visuals on Home:
`3`

Hard ceiling:
`4`

### 3.2 Free result lane
Free result lane may use:
- one chart-backed texture
- one title-card support illustration
- one blurred deeper-preview image

Do not build a scrolling gallery wall.

---

## 4. Role map by asset

### 4.1 Hero image
Role:
- represent “self-understanding through structure”
- create calm curiosity

Must not imply:
- medical certainty
- spiritual superiority
- guaranteed destiny

### 4.2 Data-support image
Role:
- sit near charts / title cards / five-element modules
- make the data feel authored, not random

### 4.3 Blurred spread teaser image
Role:
- suggest that Entry Report is a booklet-like owned object
- support purchase desire without leaking body content

### 4.4 PDF bridge image
Role:
- create continuity from Home to Entry Report booklet
- maintain same art language, deeper density

---

## 5. Blur / mask / mosaic law

### 5.1 Allowed locked-depth devices
- soft blur over chapter bodies
- mosaic over deep paragraph blocks
- cropped spread with visible section titles only
- faded chart labels with only category shells visible
- first-line reveal only

### 5.2 Forbidden devices
- dark paywall jump-scare over in-progress ritual
- impossible-to-read tiny fake body text
- deceptive “already generated, now blocked forever” theatrics
- aggressive red urgency overlays

### 5.3 Purpose rule
Blur is not punishment.
Blur exists to show:
- there is deeper owned structure
- free lane is intentionally partial

---

## 6. Midjourney / image prompt discipline

### 6.1 Prompt direction
Preferred tone:
- editorial infographic
- quiet atlas
- restrained luxury
- specimen / map / layered observation
- muted palette
- soft contrast
- white/ink/paper compositional logic

### 6.2 Prompt guardrails
Always include:
- calm
- non-occult
- no text in image
- no UI chrome baked into image
- no branding baked into image

### 6.3 Production rule
Generated images are supporting assets only.
They do not define product truth.
Product truth remains in charts, section structure, and owned report architecture.
