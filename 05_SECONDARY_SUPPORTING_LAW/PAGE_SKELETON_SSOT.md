# M55 Web Page Skeleton SSOT

Status: DRAFT FOR FREEZE
Mode: page structure law
Scope: release-night MVP and Wave A visual normalization

---

## 1. Objective

Every public M55 page must feel like part of the same product family.
This is achieved by freezing page skeleton order before further copy polish.

This SSOT defines **block order**, not final copy.

---

## 2. Global skeleton law

Every page must follow this structural logic where applicable:
1. page header / title zone
2. primary explanation or page purpose
3. main content shelf or frame
4. CTA or next-action zone
5. trust / support / legal assistive zone

Not every page needs every block, but the order must not invert.

---

## 3. Root page `/`

Required order:
1. quiet title / purpose
2. explanation before input
3. intake start surface
4. free-content shelf preview
5. DTR shelf preview
6. support/legal trust line

---

## 4. CORE / TODAY / WEEKLY

Required order:
1. shell header
2. framed legacy surface or native content shelf
3. stable primary nav

Do not add extra marketing shelves above the actual reading surface.

---

## 5. DTR lane `/dtr/lp`

Required order:
1. page title / what this product is
2. core offer card
3. purchase CTA card
4. delivery / access explanation card
5. trust links / legal / refund / support

The sell lane must not feel like a legal appendix or prototype notes page.

---

## 6. Support page

Required order:
1. page title / support promise
2. issue categories
3. contact / next-action block
4. legal / transaction references where needed

---

## 7. Success page

Required order:
1. completion acknowledgment
2. what happens next
3. where to view purchased content
4. what to do if reflection is delayed
5. support / refund / my-page links

---

## 8. My page

Required order:
1. ownership center header
2. purchases / available items
3. archive / reopen surface
4. support / issue recovery path

My page must not become a commercial homepage.

---

## 9. Skeleton consistency rules

- same title hierarchy
- same card family
- same trust link language family
- same spacing rhythm
- one primary nav only

---

## 10. Freeze summary

Before copy refinement, M55 must share one page skeleton law across root, product, support, success, and personalized reading surfaces.
