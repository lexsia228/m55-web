## Why this pack exists

既存 SSOT 群は、
- `free -> entry report -> purchaser-only concierge room`
- `consult = report attribute`
- `max consult per report thread = 3`
- `timeline family = subscription + stored history required`
を固定した。

しかし、以下はまだ不足していた。

- Home でどうフックを作るか
- 無料結果で何をどこまで見せるか
- 無料結果の中で M55 の仕組み・ルールをどう理解させるか
- Entry Report を PDF 8ページ級でどう設計するか
- 挿絵 / グラフ / モザイク / fog shelf をどう使って Entry Report をカニバらずに欲しくさせるか

本パックはその不足を埋める。

## Core decision

- public hero は引き続き `¥1,000 Entry Report` だけ
- free は「自分のデータが見えた」と感じるレベルまで厚くする
- ただし free では deep body を渡さない
- Home / free results は “controlled disclosure” で設計する
- Entry Report は PDF 8ページ級の軽量高密度設計で、無料面を明確に凌駕する
- Compatibility `¥2,000` は future/next expansion であり、current hero ではない
- Standard `¥680` は eligibility rail であり、current hero ではない
