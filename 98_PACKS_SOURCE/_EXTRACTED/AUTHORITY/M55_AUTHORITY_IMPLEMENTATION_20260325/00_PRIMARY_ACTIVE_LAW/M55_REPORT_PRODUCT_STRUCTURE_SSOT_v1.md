## 0. Executive judgment

M55 の公開面で今すぐ見せる商品は多くない方が強い。  
したがって、current public truth は `¥1,000 Entry Report` の single hero に固定する。

ただし product architecture 自体は一本化しない。
次の一手として `相性レポート ¥2,000` を保持し、
timeline/history-dependent DTR は subscription rail 側へ分離する。

## 1. Current Public Truth

This chapter is current public truth.

### 1.1 Public line
- Free
- `¥1,000 Entry Report`
- purchaser-only concierge room

### 1.2 Entry Report definition
- public label: `Entry Report`
- internal canonical: `dtr`
- category: static personal report
- topic: `ユーザーの取り扱い説明書 / トリセツ`
- timeline usage: none
- stored history dependency: none
- one-time purchase allowed: yes

### 1.3 Entry Report quantity rule
- structured body target: `2,200〜3,000 chars`
- included consult: `1 / 1`
- consult room: purchaser-only
- add-on: room-only
- thread cap: `max 3 / 3`
- no public standalone consult SKU

### 1.4 Entry Report value rule
Entry Report の価値主語は:
- static self-understanding
- structured explanation
- first clarification channel

Entry Report の価値主語ではないもの:
- timeline comparison
- stored-history leverage
- past/future axis interpretation
- generic public AI chat replacement

## 3. Subscription-Gated Timeline DTR Family

This chapter is **not** current public truth.  
It is architecture law for the next monetization layer.

### 3.1 Family definition
Any DTR that uses:
- time axis
- stored history
- comparative periods
- past-to-present or present-to-future continuity
belongs to this family.

### 3.2 Eligibility
- independent one-time purchase: no
- requires active eligible subscription: yes
- requires sufficient stored history: yes

### 3.3 Price direction
- current preferred anchor: `¥1,000`
- same visible price as Entry may be allowed
- difference is not “better result”
- difference is product category: time-axis reading with stored-history leverage

This chapter is **not** current public truth.
