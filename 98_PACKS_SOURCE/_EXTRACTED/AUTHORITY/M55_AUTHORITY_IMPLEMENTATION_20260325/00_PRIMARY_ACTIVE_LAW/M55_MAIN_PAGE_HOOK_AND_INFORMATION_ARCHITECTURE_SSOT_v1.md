## 3. Controlled disclosure rule

### 3.1 Principle
Home and free results must create hunger by structure, not by deception.

### 3.2 Allowed reveal devices
- fog shelf
- blurred chapter cards
- mosaic/soft mask on deep paragraphs
- locked section headers
- mini charts with partial labels
- first-line-only paragraph reveal
- “見えること / 購入後に深まること” comparison cards

### 3.3 Forbidden reveal devices
- hard interruption inside ritual flow
- “続きを見るには今すぐ課金” while reading live result
- fake timers
- fake price decay
- shame language
- fear-based lock copy

### 3.4 Required reveal balance
The user must leave free lane understanding:
- 自分に固有の構成がある
- M55 は無料で基礎を見せる
- Entry Report で同じ本質が深く構造化される
- 相談は購入済み report に1回付属する
- 相談は独立 public SKU ではない

## 4. Home visual modules

### 4.1 Mandatory modules
A. 五行リング / 円グラフ  
B. 五行レーダー  
C. 偏りゲージ（不足/過多の静かな可視化）  
D. タイトルカード（称号）  
E. 本質要約カード  
F. 現在の焦点カード  
G. blurred Entry Report spread teaser

### 4.2 Graph hierarchy
Primary = ring / donut  
Secondary = radar  
Tertiary = bias gauge

Reason:
- ring is easiest to read
- radar gives shape-memory
- gauge explains imbalance without ranking the user

### 4.3 Data wording rule
Do not frame charts as score / rank / performance.
Allowed framing:
- 構成
- 比重
- かたより
- 強め / ほどよい / 静かめ

Forbidden framing:
- あなたは上位◯%
- 平均以上
- 優秀度
- レベル

## 8. Mosaic / blur treatment rule

### 8.1 Purpose
Blur is not punishment.  
Blur is a boundary marker.

### 8.2 Use cases
- Entry Report page spread preview
- locked chapter cards
- “購入後に深まる本質” snippets
- secondary graphics that imply more depth exists

### 8.3 Visual tone
- soft blur, not aggressive blackout
- page edges and headings remain visible
- one teaser line can remain readable
- avoid ransom-style lock design
