## 0. Checkpoint summary

現時点の M55 は、単なる Home 仕上げフェーズから一段進み、
**大規模ピボット後の monetization / ownership / eligibility 構造を再固定する段階** に入った。

今回のピボットで重要なのは、
旧資産を「surface として復活」させるのではなく、
**Layer1 の権利・保存・所有モデルとして継承しつつ、current Web の公開面は single hero へ絞る** と決めたことにある。

一文で言うと、
**M55 は「多プランを並べるサイト」ではなく、free で自己観測を開き、`¥1,000 Entry Report` で最初の深掘りを売り、stored history を使う timeline family は subscription gate の先で開く構造へ、大規模ピボットした。**

## 1. What changed in this large pivot

### 1.1 Public hero structure was reset
公開面の主役は、複数価格帯や旧 subscription surface ではなく、
**`Free -> ¥1,000 Entry Report -> purchaser-only concierge room`** の一本線へ再固定された。

### 1.2 Product spine was clarified
M55 の商品 spine は以下へ整理された。

- Free = 自己観測の入口
- Entry Report = 最初の one-time deepening
- Compatibility Report = 次の one-time expansion
- Standard subscription = stored history / timeline moat への eligibility rail
- Premium = deferred / not-yet-primary

### 1.3 Timeline family was isolated
`timeline/history-dependent DTR` は、static report と同列に public で売るのではなく、
**subscription + stored history を成立条件とする別 family** として切り分けられた。

### 1.4 Old law was narrowed, not blindly revived
旧 monetization freeze の
`Standard ¥680` `Premium ¥1,980` `Personal DTR = 全プラン購入可 / サブスク独立`
は、current public truth として復活させるのではなく、
**Layer1 reference として保持しつつ、新方針に合わせて狭義上書き** する方針で統一された。
