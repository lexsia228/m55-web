## 1. Raw / display dual-hold rule

すべての語彙は次の2層保持を前提とする。

- `raw`
- `display`

### Raw
- source fidelity を重視
- internal / audit / golden test 用
- public 面には直接出さない

### Display
- 40〜80字程度の短い要約
- calm / non-deterministic
- page tone に合わせる
- public-safe wording に従う

## 4. Safe conversion rules

### Avoid raw direct display
- 黄金期
- 宿命
- 重大転機
- 断言口調
- 不安を煽る表現

### Safe display conversions
- 黄金期 -> 長期の流れ
- 宿命的相性 -> 関係性の見方
- 大転機 -> 変化の局面
- 全振り -> 優先テーマ
- 撤退の二字はない -> 継続して押し進める傾き
