## 2. Background NoTouch（憲法レベル）

- **`html` / `body` のキャンバス**（ページ全体の背景グラデーション等）を **シェル CSS で再定義しない**。
- 視覚の「面」は **各ページ／モジュール CSS** または **コンポーネント直下のラッパー** に閉じる。
- 参照実装: `app/globals.css` は margin / box-sizing のみ（コメントで NoTouch を明記）。

## 3. カラー（v1 正本）

| トークン | 値 | 用途 |
|----------|-----|------|
| `--m55-accent`（論理名） | `#7c6fd6` | ラベルアクセント・アイライン・プライマリ CTA 塗り |
| `--m55-text-primary` | `#2f2640` | 見出し・本文主軸 |
| `--m55-text-muted` | `#6b5b8a` | 説明・補助文 |
| `--m55-text-link` | `#5a4a7a` | テキストリンク（セカンダリ） |
| `--m55-surface-tint` | `rgba(250, 246, 255, 0.98)` 等 | **ページ内**サーフェス（例: 購入成功の `.page`）。グローバル背景の代替には使わない |
| `--m55-border-soft` | `rgba(177, 156, 255, 0.12)` 〜 `0.35` | カード境界のソフトボーダー系（観測レンジ） |

**注:** シャドウ系 `rgba(29, 24, 61, 0.04–0.12)` は CHECKPOINT 観測レンジとして許容。新規画面では **既存コンポーネントの既存トークンに合わせる** ことを優先する。

## 4. タイポグラフィ（v1 正本）

| トークン | 目安 | 用途 |
|----------|------|------|
| `eyebrow` | ~11px, weight 600, letter-spacing 広め, uppercase 可 | 製品ラベル（例: Entry Report） |
| `title` | ~1.25rem | ページ見出し |
| `body` | ~0.875rem | 説明文 |
| `secondary` | ~0.8125rem | フッターリンク列 |

フォントファミリーは **システム／既存 shell 既定** に従い、本書では新規フォント導入を定義しない。

## 5. CTA 階層（v1 正本）

| 階層 | 表現 | 備考 |
|------|------|------|
| Primary | 塗りつぶし・角丸ピル（例: `border-radius: 9999px`）、アクセント背景 | 1 画面 1 主目的 |
| Secondary | 下線付きテキストリンク | マイページ・サポート等 |
| Tertiary | 区切り `·` 付きの低コントラスト行 | 補助遷移 |

## 7. モーション・アクセシビリティ

- **無限ループアニメーションを設けない**（`prefers-reduced-motion` への配慮は既存 M55 方針に従う）。
- ローディング表現は **チャット／チャンク用途の既存パターン** に合わせ、本書では新パターンを増やさない。

---

## 8. データ属性（回帰テスト用・参照のみ）

購入成功などで既に定義されている `data-testid` は **契約** として扱い、リネームは Review 付きで行う。

- 例: `m55-purchase-success-main`, `m55-purchase-success-headline`, `m55-purchase-success-primary-cta`
