# M55 Visual System

Status: **Visual authority (Tier D)**  
Reference surface: HOME commercial foundation (`CLOSED_GREEN`)

## Palette and tone

- deep navy
- warm ivory
- muted blue-green
- restrained coral
- editorial Japanese typography
- fine hairlines
- controlled whitespace
- dark Hero
- dark Premium stage

## Prohibited patterns

- generic card 乱用
- heavy shadow
- glassmorphism 乱用
- 不自然な日本語語中改行

## Cross-funnel principle

HOME だけが高品質では不十分。以下も同等品質:

- 無料入力
- 無料結果
- 購入画面

## Layout rules

- 大量の意味のない空白を作らない
- CTA を長い本文へ埋没させない
- stock image が商品理解を弱める場合は使用しない
- 同じ結果を無制限生成できる印象を与えない

## Scope note

This SSOT governs **commercial funnel surfaces**. Ten-views typography unification is a separate lane (`M55_ROADMAP.md` step 7).
