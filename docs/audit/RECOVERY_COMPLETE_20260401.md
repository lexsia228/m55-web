---

## 6. Git + 監査文書 + スナップショットの三層防御

| 層 | 役割 |
|----|------|
| **Git** | 変更の履歴、ブランチ、差分の再現性。コードと設定の権威ある時系列。 |
| **Audit doc**（本類の文書） | いつ・なぜ・どの基準で復旧・固定したかの人間可読な説明とポリシー。 |
| **Snapshot** | 特定時点のファイル集合の物理的退避。Git 外の検証・オフライン保持・比較用。 |

三層すべてが揃うことで、単一の欠損（履歴のみ／文書のみ／ファイルのみ）でも復元・説明・検証のいずれかを補完できるようにする。
