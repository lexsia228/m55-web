# M55 Final Human Copy Review Packet Storyflow v1

## 1. この資料の目的

- `M55_FINAL_HUMAN_COPY_REVIEW_PACKET_v1.md` は監査型（抜け漏れ確認）パケットです。
- 本資料は、読み心地・感情の流れ・起承転結を確認するための Storyflow パケットです。
- これは実装 SSOT ではありません。
- これは商品仕様を変更する資料ではありません。
- ユーザーは「読みやすいか」「あたたかいか」「流れで追えるか」を中心に印を付けます。

## 2. M55 Storyflow 原則

### M55版 起承転結

- 起: お題
- 承: あるある
- 転: 転換
- 結: 読み解き -> 次の一手

### 1画面 = 1シーン

- 1画面で全部を説明しない
- 1見出し = 1トピック
- 1ブロックは短く保つ
  - 見出し 1行
  - 本文 2〜3行
  - 次の一手 1行

### 強弱ルール

- 先に短いフックを置く
- 次に具体的な日常場面を置く
- その後に M55 の読み解きを置く
- 最後は小さな安心と行動で閉じる

### 禁止

- 長い平坦な説明ブロック
- 仕事/キャリアをデフォルト軸にする構図
- 汎用アドバイス調
- 運命断定
- 医療/治療の約束
- 汎用チャット約束
- 無制限相談
- 通知メール約束

## 3. Product truth guardrails

- 本質の読み解き
- 保存版
- 4章
- 相談返書
- 付属1
- 追加最大4
- 合計5
- 追加500円
- 購入時点プロフィール
- 保存版に紐づく相談
- 汎用チャットではない
- 通知メール約束なし
- 無制限相談なし
- なんでも答える約束なし
- 医療・治療の約束なし
- engine/snapshot/result-label をこのpacketで変えない

## 4. Human marking method

各項目に以下を付与:

- OK
- 柔らかくする
- 意味がわからない
- 仕事っぽい
- もっと人間関係へ
- 削る
- 強める
- 流れが悪い
- お題が弱い
- あるあるが足りない
- 転換が弱い
- 次の一手が弱い

Concern flags:

- 冷たい
- 抽象的
- 営業っぽい
- 決めつけが強い
- 説明が長い
- 動画っぽくない

## 14. 参考例から吸収する技術

### 採用する技術

1. Not A, But B
- 先に責めを外す
- その後に構造を説明する
- M55-safe example:
  - 「理解できていないわけではありません。保存版の内容と、今の場面をつなぐ一歩が必要なだけです。」

2. 数字のフレーミング
- 数字を冷たい仕様として並べない
- purpose -> 付属1 -> 追加最大4 -> 合計5 -> 追加500円 の順で伝える
- M55-safe example:
  - 「まず付属1件で整理できます。必要なときだけ、追加で最大4件まで深められます。合計5件まで利用できます。」

3. マイクロ・コミットメント
- 相談の負荷を小さくする
- use:
  - 1つだけ
  - 1行だけ
  - 今の場面だけ
  - 近いものを選ぶ
- M55-safe example:
  - 「まずは、いちばん近いテーマを1つ選んでください。自由入力は、短く1行だけでも大丈夫です。」

### 弱める表現

- 重すぎる心理描写
- 救済感が強すぎる表現
- 依存感が出る表現
- 販売口語が軽すぎる表現

### 使わない表現

- カルテ
- メンタル
- 心の反応
- 胸の奥が苦しい
- 心の避難所
- フラッシュバック
- 私たちに預けて
- きっと見つかる
- 傷つかないため
- ワンコイン
